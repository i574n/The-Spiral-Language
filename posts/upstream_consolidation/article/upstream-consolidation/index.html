This is the first of a series of small posts, one per pull request, about the fork of The Spiral Language. It starts from vanilla: everything here is work that already exists upstream but never reached master, plus fixes for bugs we found in that work. It adds no features of our own; those come in later posts.

The core: corebase becomes core

The ML library's corebase is the newest core. Each module was judged on its own; where the old core did something better, it was kept.

ModuleFromDecisionWhy
basecorebasetake, extendorder stays the old nominal over i32 (keep-old: corebase's three-case union materializes a runtime enum and a match where comp a b |> gt_is on strings used to be one comparison; x's view crate grew past the 1k gate on it), hashable returns u64, arrays become one-dimensional array t indexed by int; the sa, da, sa_list and da_list nominals switch only over Cpp and Python and need an arm per backend
real_corecorebasetake, extendadds sqr, divup, modup, existential and singleton predicates, nominal_recreate, union_type helpers; assert keeps the old core's runtime failwith, because corebase's native assert arms exist only for Python, C++ and CUDA (a compile error on every other backend) and C++ assert vanishes under NDEBUG; hash switches only over Fsharp, Python, Cpp and Cuda and needs an arm per backend; structural (<>) lowers primitives to NEQ (SPIRAL-CORE-NEQ)
corecorebasetakeadds bitwise complement, heap_refs, stack_refs, to_fptr, to_closure, tlit, union_map and record_map; the ~* and ~! deref operators are kept from the old core (keep-old: the fork's edition 3 lowers unary *x to a call of ~*, while upstream's parser builds RawLayoutIndex directly, so upstream never calls them and keeping them costs nothing); the backend_switch_* helpers name only Cpp, Cuda and Python and are judged with the backend arms

dictm, dictm_type, dictm_utilsolddropPython-only despite the generic look: its buckets are the old ra Python list (rm.add, rm.pop) and keys go through hash_cython; corebase's corecudahost dictm is its newer CUDA-host successor; a dictionary for every backend needs growable buckets over array t and a backend-neutral hash, which is new work, not a port
